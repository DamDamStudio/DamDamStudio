웹그대로 개인정보 처리방침

웹그대로는 Safari에서 사용자가 선택한 웹페이지 요소를 숨기고, 일부 웹사이트의 앱 유도 팝업과 배너를 숨기는 기본 설정을 제공하는 확장 프로그램입니다.

웹페이지의 내용과 현재 페이지 주소는 사용자가 허용한 사이트에서 요소를 선택하고 숨김 규칙을 적용하기 위해 기기 안에서만 처리합니다. 웹페이지 내용이나 방문 기록을 운영자의 서버로 전송하거나 저장하지 않습니다. 회원가입, 앱 내 광고, 사용자 추적, 분석 SDK, 원격 규칙 다운로드를 사용하지 않습니다.

사용자가 직접 추가한 사이트의 호스트 이름, 선택한 요소를 찾기 위한 CSS 선택자, 사이트·규칙별 켜기·끄기 등 설정과 최근 확장 연결 시각을 앱과 Safari 확장이 함께 사용하는 기기 내 저장 공간에 저장합니다. CSS 선택자는 페이지 요소의 태그·ID·클래스·구조 등을 이용해 해당 요소를 다시 찾는 값입니다. 페이지 본문이나 입력한 양식 내용을 저장하는 기능은 없습니다.

사이트를 추가할 때 입력하거나 Safari에서 확인한 HTTP·HTTPS 주소에서는 호스트 이름만 저장합니다. 전체 페이지 주소의 경로·쿼리·프래그먼트·포트는 저장하지 않습니다. 하위 도메인은 별도로 관리하며, 저장된 사이트와 규칙은 앱 또는 Safari의 웹그대로 메뉴에서 삭제할 수 있습니다. 이 목록은 사용자가 추가한 설정이며 방문한 페이지 목록을 기록하는 기능이 아닙니다.

최근 확장 연결 시각은 앱에서 확장과 설정이 연결되었는지 안내하기 위한 값이며 사이트 주소를 포함하지 않습니다. 저장된 호스트 이름·CSS 선택자·설정·연결 시각을 운영자의 서버로 전송하지 않습니다.

Safari의 웹사이트 접근 권한은 사용자가 Safari 설정에서 관리할 수 있습니다. 웹그대로가 해당 사이트에 접근하는 것을 원하지 않으면 사이트별 접근 권한을 거부하거나 확장을 비활성화할 수 있습니다. 접근 권한을 끄는 것과 앱에 저장한 사이트·규칙을 삭제하는 것은 별개의 조작입니다.

앱 구매 및 다운로드 결제는 Apple의 App Store에서 처리하며 웹그대로 운영자가 카드번호나 Apple 계정 비밀번호를 받지 않습니다. 사용자가 별도로 보내는 지원 문의에는 이메일 주소와 사용자가 직접 기재한 내용이 포함될 수 있으며, 문의에 답변하기 위해 사용합니다. 비밀번호·인증 코드·결제정보나 민감한 페이지 주소를 문의에 포함하지 마세요.

테스트 배포인 TestFlight와 Apple의 운영체제·App Store 서비스는 Apple의 정책에 따라 진단/테스트 정보를 처리할 수 있습니다. 웹그대로는 웹페이지 내용이나 방문 기록을 추가로 수집하는 기능을 제공하지 않습니다.
