웹그대로 지원

아래 사용자 지정 기능은 다음 배포 후보의 안내입니다. 새 기능의 실제 Safari·실기기 검증과 TestFlight·출시 준비를 진행하고 있으며, 공개 다운로드 링크는 아직 제공하지 않습니다.

내 사이트·숨길 요소 직접 선택

웹그대로는 Safari에서 사용자가 선택한 웹페이지 요소를 숨기는 확장 프로그램입니다. 사이트를 직접 추가하고 Safari의 웹그대로 메뉴에서 요소를 선택해 나만의 규칙을 저장할 수 있습니다.

Reddit(www.reddit.com), Imgur(imgur.com), 知乎(www.zhihu.com)의 일부 앱 열기 안내용 기본 설정도 제공합니다. 모든 사이트·요소·팝업의 작동을 보장하지 않으며, 사이트 구조가 바뀌면 요소를 다시 선택해야 할 수 있습니다.

처음 사용하는 방법

  1. 웹그대로 앱에서 Safari 확장 활성화 안내를 확인합니다.
  2. Safari의 페이지 메뉴에서 확장 프로그램 관리를 열거나, 기기의 설정 → 앱 → Safari → 확장 프로그램에서 웹그대로를 켭니다. iOS 버전에 따라 메뉴 이름이 다를 수 있습니다.
  3. 사용할 사이트의 접근을 허용합니다. 접근 권한은 사용자가 Safari에서 관리할 수 있으며, 설정 바로가기가 일반 앱 목록을 열면 앱 안의 수동 안내를 따라가세요.
  4. 기본 설정을 사용할 때는 앱에서 해당 사이트 설정을 켜고 Safari 페이지를 새로고침합니다.

내 사이트와 규칙 추가하기

  1. 앱에서 호스트 이름이나 HTTP·HTTPS 주소를 입력하거나, Safari의 웹그대로 메뉴에서 현재 사이트를 추가합니다.
  2. 같은 메뉴에서 요소 선택을 시작하고 비민감 요소를 선택합니다. 필요하면 상위 요소로 범위를 조정하세요.
  3. 숨김 미리보기로 확인한 뒤 저장하거나 취소합니다. 취소하면 미리보기를 끝내고 원래 표시로 돌아갑니다.
  4. 설정 변경 뒤 페이지를 새로고침합니다. 사이트와 저장한 규칙은 앱 또는 웹그대로 메뉴에서 켜고 끄거나 삭제할 수 있습니다.

주소에서는 정확한 호스트 이름만 저장합니다. 경로·쿼리·프래그먼트·포트는 저장하지 않으며, example.com과 www.example.com처럼 하위 도메인은 별도로 추가해야 합니다. 같은 호스트의 HTTP·HTTPS 페이지에 규칙이 적용될 수 있습니다.

사용자 지정 규칙은 선택한 요소를 숨기며 일반적인 스크롤 잠금을 임의로 풀지 않습니다. 입력 양식, 로그인·결제·보안 관련 화면 등에서는 선택이나 적용이 제한됩니다. 페이지 구조에 따라 선택할 수 없는 요소도 있습니다.

숨김이 작동하지 않거나 화면이 불편할 때

앱 또는 웹그대로 메뉴에서 해당 규칙이나 사이트의 숨김을 끄고 Safari 페이지를 새로고침하세요. 사이트가 구조를 바꾸면 저장한 CSS 선택자가 더 이상 맞지 않을 수 있습니다. 이전 규칙을 삭제하고 비민감 요소를 다시 선택할 수 있습니다.

Safari 자체 Smart App Banner, iOS 앱 열기 확인과 다른 앱의 인앱 브라우저는 대상이 아닙니다. 모든 광고나 팝업을 자동으로 일괄 숨기지 않으며, 로그인·결제·본인 인증·보안 확인·유료 콘텐츠 제한을 제거하거나 우회하지 않습니다.

사용자 지정 기능의 실제 Safari·실기기 동작과 모든 사이트 변형은 검증 완료로 주장하지 않습니다. 앱 안의 숨김 전·후 화면은 가상 예시이며 실제 사이트 설정을 바꾸지 않습니다.

기기 안에서 관리하는 정보

추가한 호스트 이름, 요소를 찾기 위한 CSS 선택자, 설정과 최근 확장 연결 시각을 기기에 저장합니다. 전체 페이지 주소·페이지 내용·방문 기록을 앱에 저장하거나 운영자에게 전송하지 않습니다. 자세한 내용은 개인정보 처리방침을 확인하세요.

사이트 접근 권한을 끄는 것과 저장한 사이트·규칙을 삭제하는 것은 별개입니다. 접근 권한은 Safari에서, 저장 목록은 앱 또는 웹그대로 메뉴에서 관리할 수 있습니다.
